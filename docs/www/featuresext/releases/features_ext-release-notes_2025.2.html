The task list below represents our "dynamic" roadmap for the Extensions SDK. Looking at it will give you a better sense of the features, upgrades, and bug fixes that we are currently working on. Typically, not all of the items listed below will make it into the future release of the SDK. Still, you can see what's around the corner not waiting for the official releases.

SMRU, DXF

  • [SMRU] Report face IDs of the base faces a hole belongs to.
  • [SMRU] Incremental mode of bending sequence simulation if bend groups cannot be unfolded.
  • [SMRU] Animation file for bending sequence simulation.
  • [SMRU] #1118: Make feature recognition report the named B-rep entities corresponding to the serial face IDs.
  • [SMRU] Instability of test cases on Linux.
  • [SMRU] CI/CD for linux builds.
  • [SMRU] Advanced algorithm for laser-cut parts having machining features.
  • [SMRU] #1060: Face IDs of the closest cutout are demanded for better DFM reporting.
  • [SMRU] #1034: Compute and report the convex hull of a flat pattern.
  • [SMRU] #1069: Holes that have full-depth countersinks not having a correct hole location.
  • [SMRU] #1070: An inconsistent assembly item ID is reported for a welding candidate component.
  • [SMRU] #1072: Flat hem detection affects extreme cases only.
  • [SMRU] #1056: Distances between features.
  • [SMRU] #1120: Profile remains unrecognized because of a large cut.
  • [SMRU] #1121: Introduce a Boolean flag to indicate that the "extruded aluminum" profile is of rectangular type.
  • [SMRU] #1126: Add compensation for countersunk and counterbored drilled holes for the sake of more precise reporting of 3208.
  • [SMRU] Add defeaturing to bending sequence simulation.
  • [SMRU] #1140, ...: Improve recognition of thick plates.

CNC

  • [CNC] Introduce strategies for negative volumes: off, regular polygons, raw prisms, normalized point clouds.
  • [CNC] #1104: A planar face for a simple CNC part does not get side-milling type of a feature
  • [CNC] #1105: Add missing accessibility test for through holes.
  • [CNC] Find a way to match the MTS faces with the original CAD faces of a turned+milled part and this way simplify the relationships between the reported entities.
  • [CNC] #1123: Crash in H tessellator for a turned part if executed in batch mode (without part visualization)
  • [CNC] Keep fillet and chamfer chains grouped.
  • [CNC] Parallel processing for thickness?
  • [CNC] Recognition of c-pockets.
  • [CNC] Introduce optional machining ops (setup finder).

ALM

  • [ALM] Add thickness analysis as an option for 3D printing toolbox.

Common

  • [Common] Sphere-based thickness analysis.
  • [Common] Enable parallel face discretization in Faceter.
  • [Common] PDF report generator.

Simplification

  • [Simplification] Introduce simplification SDK.
