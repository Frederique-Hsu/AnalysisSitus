Release notes ver.2024.2

Analysis Situs Extensions ver.2024.2 accumulate hundreds of patches in the SMRU, CNC and DXF software development kits. The most important updates are highlighed in the corresponding changelogs below. Contact us for more information on licensing the SDKs.

CNC, DFM

  • [DFM] Improve performance of the horizontal tessellator algorithm for turned parts.
  • [DFM] Get rid of width-based filtering for false-positive thickness spots.
  • [CNC] Fix #692 with a bored sphere misrecognized as a turned feature.
  • [CNC, DFM] Rework prismatic configurations.
  • [CNC] #695: Fix incomplete counterbores with chamfers.
  • [DFM] Fix #643: `maxConcaveCurvature` is always null as it seems to be never computed for surface types other than cylinders and cones.
  • [CNC, DFM] Add "recognition strategy" parameter to `InspectFile`.
  • [CNC] #721: Pass "domain" face IDs to all recognizers.
  • [CNC] Add '-type' flag for setting the recognition strategy in `asiCncExe`.
  • [DFM, CNC] Export MTS in DFM (#579).
  • [CNC] Add '-aag' option to the CNC recognition SDK (#743).
  • [CNC] #742: Add reorientation option for automatic alignment of parts.
  • [CNC] Fix #674: Add `-allowSharp` flag to allow for the recognition of pocket walls with sharp corners.
  • [CNC] Add protection against null or parallel vectors on computing milling axes for blends.
  • [CNC] #752: Output IDs of the unrecognized faces to JSON.
  • [CNC] #556, #975, #977, #1010: Improve the recognition logic for axial grooves to prevent boring/turning global inversion.
  • [CNC] #1013: Report the unrecognized faces for turned+milled parts.
  • [CNC] #1013: Check for global outliers between turned faces to improve accuracy of turning recognition.
  • [CNC] Speed up detection of global obstructions for turned faces by caching the maps of vertices and ranges.
  • [CNC] Fix #724: Output original units and scale factor.
  • [CNC] Fix ambiguity in feature color sorting; do not use non-side milling axes in side contour grouping.
  • [CNC] Introduce computation of inaccessible vertices in CNC.
  • [CNC] Fix #887: Make `cncCode_PartBody_Warn_ImpossibleCorner` also report face IDs.
  • [CNC] #753: Move DFM logic for pointwise depths from the DFM to CNC package.
  • [CNC] Make 3-axes milled faces a standard CNC function.
  • [CNC] Fix #965: Do not let the algorithm set any limits on hole diameters on recognition if the user has not provided any.
  • [CNC] Rework CNC testing assets; introduce the novel `cnc-run-tests` command.
  • [CNC] Make feature comparator symmetric to prevent debug assertion crash due to disrespecting cpp reference.
  • [CNC] Get rid of useless `asiCncTest` package.
  • [CNC, DFM] Merge DFM checks to the CNC recognition toolset.

SMRU, DXF

  • [DXF] Add C# wrapper for the DXF library (#661).
  • [SMRU] Add `axialCuttingRange` property for tubes/profiles (Fix #663).
  • [SMRU] Report `bends` for the `TUBE_OTHER` type; fix segments reporting for flat shapes.
  • [SMRU] Analyze accessibility of engravings on tubes.
  • [DXF] Do not mix text contours edges with the normal cutting contours (#691).
  • [SMRU] Compute bbox dimensions of the entire assembly (Fix #712).
  • [SMRU] #715: Report the `closestParallel` and `closestParallelFaceId` properties for inner cutouts on tubes.
  • [SMRU] Introduce the closest parallel length.
  • [SMRU] Recognize rolled cylinders and generalized cylinders (#708).
  • [SMRU] Improve `isLeaf` property determination for rolled flanges.
  • [SMRU] Introduce another (topological) finder for boundary cuts in round tubes.
  • [SMRU] Make `asiSheetMetalExe` dump part images (introduce '-imagesForParts' flag).
  • [SMRU] Introduce '-expandCompounds' parameters for automatic break down of compound parts into elementary shapes (Fix #732).
  • [SMRU] CAD-729: Modification of K-factor does not affect `totalCuttingLength`
  • [SMRU] Get rid of the `ToPerform` flag in `ProfileParams` which has been unclear for the SDK users (#718).
  • [SMRU] Revise diagnostic codes and extend the '-lookup' mechanics for searching diagnostic codes in the reference files.
  • [SMRU] Get rid of paddings in SVG images exported from SMRU.
  • [SMRU] Make drawings aligned smartly in SVG export.
  • [SMRU] Fix #795: Introduce non-uniform thickness check.
  • [SMRU] Fix #788: Make sure to generate JSON for broken STEP files.
  • [SMRU] Fix #798: Fix problem with floating point separator for the `cornerRadius` property of tubes.
  • [SMRU] Restore the priority of engraving color over inner feature color.
  • [SMRU] Introduce '-expand' flag in `sm-perform`.
  • [SMRU] Fix #252: do not report 3208 for tubes.
  • [SMRU] Use a more reliable way of defeaturing that does not corrupt shapes.
  • [SMRU] Fix #864: Report `area` for each `cutout` object.
  • [SMRU] Provide API to analyze an existing `TopoDS` shape passed to the recognition from the client code.
  • [SMRU] Recognize non-isolated cutouts (Fix #739, Fix #876, Fix #601).
  • [SMRU] Compute area for folded cutouts.
  • [SMRU] Fix #878: Why 3302 "Abnormal bending" is reported for a seemingly valid tube?
  • [SMRU] Fix #645: Compute bend length for rolled flanges.
  • [SMRU] #875: Add `cutInBend` property for cutouts.
  • [SMRU] Speed up hole info collection by getting rid of heavy dtors.
  • [SMRU] Fix the incorrectly recognized engraving (#881).
  • [SMRU] Fix #861: File is not recognized as rectangular tube because of small redundant faces.
  • [SMRU] Add test cases for bend simulation.
  • [DXF] #891: Introduce `evaluateDxfExe` utility to assess the complexity of DXF files.
  • [SMRU] Fix #890 by reworking the alignment check for flat parts and redesigning the alignment logic to the same algorithm as used in the `cnc-orient` command.
  • [SMRU] Fix #928: Incorrect computation of closest cutout distance.
  • [SMRU] Unify `partLength` property for straight tubes and wires.
  • [DXF] Make tolerance an argument of `dxf-read` to control contouring precision.
  • [SMRU] Unify the `sectionDiameter` and the `diameter` properties for round tubes and wires.
  • [DXF] Print $ACADVER (DXF version) on `dxf-read` execution.
  • [SMRU] Improve recognition of round tubes by disabling unsuitable check for isolated freeform thickness faces.
  • [SMRU] Add protection against empty flat patterns where their dimensions are computed.
  • [SMRU] Fix #948: Use absolute engraving depths (2 mm default).
  • [SMRU] Fix #950: Complex hole reported for a countersink hole.
  • [SMRU] Initialize flags in ctor of `InspectFile`.
  • [SMRU] Report `countersinkDiameterOpposite` and `countersinkAngleOpposite` for double countersunk holes (#949).
  • [SMRU] Fix #987: Add max engraving depth as an option for `asiSheetMetalExe`.
  • [SMRU] Fix #989: Introduce "thickness hint" argument.
  • [DXF] #945: Fix slot-like cutouts shape corruption.
  • [SMRU] Update the default k-factor to 0.4468.
  • [DXF] Dump JSON to UI dialog in `dxf-perform` command if JSON filename is omitted.
  • [SMRU] Fix #1022: Introduce global planarity check to filter out false-positive "folded" parts, which are actually flat.
  • [SMRU] Fix #1027, Fix #1023: Report unrecognized faces as a separate semantic code.
  • [SMRU] Fix #1009: Improve the heuristic for assigning "bend" attributes to profile's sheet faces.
  • [DXF] #1025: Disable replacement of invalid contours by qhull.

Common

  • [SMRU, CNC] #675 Enrich glTF output with colors of detected features.
  • [SMRU, CNC] #713 Output STEP files with colored feature faces.

  • [Utils] Make `colorizeExe` utility independent of `asiDfm` (retired) package.
  • [Utils] Convert DXF files to SVG files (#954).
  • [Common] Fix #995: "Debug error: abort() has been called" on installed version of the SDK.
  • [Utils] Add `makeProjectionExe` utility.
  • [Utils] Prepare an executable to generate drawings in batch mode.
  • [Utils] If no direction is passed but the DXF filename is given, use the guessed direction.
  • [Faceter] Add executable for the Faceter.
