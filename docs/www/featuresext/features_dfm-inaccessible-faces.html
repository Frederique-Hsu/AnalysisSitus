Detect inaccessible faces

Inaccessible faces are detected for milling features by raycasting the part's geometry in the specified ("approach") directions. To enable this test, pass the optional -fx argument to cnc-check or cnc-perform command in the Active Script session: 

> clear; load-part ex-milling_01.stp
> cnc-check -fx

The results of this test depend on the specified inspection directions. E.g., faces may appear partially inaccessible if they are angled w.r.t. the global coordinate axes and if those axes are used for the check:

The analysis begins with choosing the candidate "approach" axes.

Like other "heavy" DFM checks, face accessibility analysis employs mesh-based representation of the part. Uniform surface paneling technique is used to obtain dense-enough triangulations.

Each triangle is raycasted in the directions opposite to the specified "approach" directions.

The facets that remain "hidden" from all the "approach" directions are reported. Their corresponding face IDs are reported as well. The warning code used for face accessibility issues is cncCode_PartBody_Warn_InaccessibleFaces.
