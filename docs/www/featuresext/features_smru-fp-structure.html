SMRU flat pattern structure

To access the unfolded flat pattern programmatically, you can iterate the inspection results by parts and bodies as the following code snippet illustrates: 

// Iterate over individual parts (`res` is the inspection result).
PartResultMap::Iterator it( res->PartResults );
//
for ( ; it.More(); it.Next() )
{
  // Iterate over bodies.
  const Handle(PartResult)& partResult      = it.Value();
  const PartBodyResults&    partBodyResults = partResult->GetBodyResults();
  //
  for ( PartBodyResults::Iterator bresIt(partBodyResults); bresIt.More(); bresIt.Next() )
  {
    const Handle(PartBodyResult)& bodyRes = bresIt.Value();
    const TopoDS_Shape&           fp      = bodyRes->GetFlatPatternShape();
    //
    BRepTools::Write(fp, "fp.brep");
  }
}

The following diagram illustrates the structure of the flat pattern shape: 

  COMPOUND 1 // Root shape
  |
  +- Maximized face // No bends, all flat faces are merged into one
  |
  +- COMPOUND 1.1 // Details
    |
    +- COMPOUND 1.1.1 // Flattened flanges
    |  |
    |  +- Flat flange 1 // Face
    |  +- Flat flange 2
    |  +- ...
    |
    +- COMPOUND 1.1.2 // Flattened bends
    |  |
    |  +- Flat bend 1 // Face
    |  +- Flat bend 2
    |  +- ...
    |
    +- COMPOUND 1.1.3 // Bend lines
        |
        +- Bend line 1 // Edge
        +- Bend line 2
        ...

The flat pattern shape is a compound that includes not only the part's flat geometry, but also such details as flat flanges, unwrapped bends, and bend lines.

The maximized face contains only cutting lines. Its contours are supposed to be processed by a cutter tool.

The flattened flanges represent the unfolded flanges of the model. These faces can be used for attaching measurement points and dimension lines.

The unwrapped bends are reported as a separate compound of faces:

Bend lines are reported as a plain list of edges in the compound 1.1.3:

The following code snippet illustrates how to access bend lines from the flat pattern's compound in C++: 

// Let `fp` be the flat pattern shape (COMPOUND 1).
TopoDS_Shape fp = ...

// Get maximized face as `mxFace`.
TopoDS_Iterator fpIt(fp);
TopoDS_Shape mxFace = fpIt.Value();

// Move on to COMPOUND 1.1
fpIt.Next();
{
  // Iterate COMPOUND 1.1
  TopoDS_Iterator fpIt2( fpIt.Value() );

  // Move on to COMPOUND 1.1.3
  fpIt2.Next(); // Skip COMPOUND 1.1.1
  fpIt2.Next(); // Skip COMPOUND 1.1.2
  TopoDS_Shape blComp = fpIt2.Value();

  // Iterate COMPOUND 1.1.3 to access bend lines as edges
  for ( TopoDS_Iterator blIt(blComp); blIt.More(); blIt.Next() )
  {
    const TopoDS_Edge& blEdge = TopoDS::Edge( blIt.Value() );

    // Do what you need with the bend line `blEdge`...
  }
}

The reported bend lines can be used to export them as dashed lines in a separate DXF layer and for conducting measurements.
