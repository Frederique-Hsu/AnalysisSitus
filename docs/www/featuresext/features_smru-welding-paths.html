SMRU welding paths

SMRU is capable of automatically detecting potential welding zones between CAD components. This analysis is entirely geometric, which means that SMRU finds assembly components that are in contact with each other with little to no proximity. It is the caller application's responsibility to further analyze the identified contact zones. One common use case is to present the reported contact zones to the end user for an interactive selection of welding pathways.
