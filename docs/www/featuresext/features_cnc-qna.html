CNC recognition FAQ

Question: What is the purpose of milledFaces3Axes array in JSON and why the faces reported there are repeated in feature objects of the same JSON?
Answer: In milledFaces3Axes, we present an entire universum of faces and their basic attributes. The faces from the universum are then organized in the feature objects according to their machining axes. Please keep in mind that just because a face is reported in the milledFaces3Axes array doesn't mean it shouldn't be mentioned in its respective feature. The milledFaces3Axes array is not a feature array; rather, it provides supplemental information for faces to report their self properties. If you are only interested in the features, you can ignore this array.

Question: What is the purpose of isMachinable and isAccessible flags reported for faces?
Answer:

The Boolean flags isMachinable and isAccessible are reported per each machining axis. These axes are used to group faces into features and have no direct use in the client applications. You can verify those flags by running cnc-recognize-axes command in Analysis Situs UI.

Green color means the axis is machinable, red — not.

Question: For turned parts, internal grooves are harder to fabricate. Do you have accessibility analysis for internal grooves?
Answer:

Accessibility tests are only performed on milling features since they work under the assumption that a cylindrical mill is approaching a face along one of the identified axes. Such "visibility" checks are not performed for turning because they would clearly result in false-positive errors. Instead, each detected negative cell is classified with respect to the stock and MTS geometries.

We are not aware of any machining issues for such grooves: our customers are satisfied with the properties that are currently reported. However, we are open to adding more DFM checks for lathed parts if they are formalized.
