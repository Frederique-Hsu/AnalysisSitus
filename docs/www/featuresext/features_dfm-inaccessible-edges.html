Detect inaccessible edges

Inaccessible edges are detected for milling features by analysis of concavity and also by raycasting the part's geometry in the directions of neighboring faces. To enable this test, pass the optional -ex argument to cnc-check or cnc-perform command in the Active Script session: 

> clear; load-part ex-milling_01.stp
> cnc-check -ex

Lathed features are ignored in this check. Therefore, edge accessibility analysis is only conducted for milling features.
