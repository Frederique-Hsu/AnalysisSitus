Complete sheet metal workflow

This guide walks you through the complete workflow of sheet metal processing in Analysis Situs CAD environment. We start with a blank sheet and then apply different tools for feature recognition and shape interrogation to help you understand the capacities of the Analysis Situs kernel with its application to sheet metal industry.

This guide uses Analysis Situs GUI for demonstration of the kernel's capacities. It should be noted that all the same steps can be conducted without interaction in either the batch mode or programmatically through the API functions.

Get a CAD part to inspect

Open source

Most people prefer using professional CAD systems (such as Fusion or SolidWorks) to prepare the production-ready solid models of sheet metal parts. In Analysis Situs, it is possible to draw conceptual designs of folded geometries, although in the production environment you will likely have to deal with imported CAD parts.

Import CAD part

To import a CAD part, use the load-part Tcl command. In most cases, the input CAD format is STEP. If you want to plug in more formats (such as SolidWorks, Inventor, Catia, etc.), it is doable with the help of our partner organization. Contact us for more details on the allowed input formats.

You may also want to configure input settings for the STEP translator. To do so, use the "STEP" button from the "Load from" menu.

The dialog that shows up on your screen allows setting up a bunch of advanced parameters of the translator. In most situations, you will prefer using the default parameters here.

Design from scratch

One way to design a simple sheet metal part for testing is to execute the following Active Script commands: 

> smm-make-block
> smm-make-edge-flange

The second command smm-make-edge-flange opens up a dialog for flange definition.

It should be noted that modeling is done in a direct manner, i.e., no feature tree or a history of operations is being memorized during the modeling process. Each time you click at an edge to construct another flange, Analysis Situs makes a local feature recognition attempt to decide on material thickness and the bend direction (UP or DOWN).

Other modeling operations are perfectly allowed. E.g., you may want to apply miters (chamfers) or round the flange corners.

Recognize and unfold

Commercial

Once your sheet metal part is ready (either imported or designed from scratch), you can recognize it and build a flat pattern. For that, use the sm-perform Active Script command.

This is where SMRU (Sheet Metal Recognition and Unfolding) algorithms come into play. The part is automatically oriented and unwrapped with the configurable k-factor at bends. Upon completion of processing, you will be given the JSON outcome with all shape properties serialized.

The flat pattern can be consulted in plenty of ways. To check the bending lines with the serial IDs as they are reported in the JSON outcome, navigate over to the "Domain" view. If several bends happen to be grouped together, you will see the same ID near their glyphs.

To save the recognition artifacts to the filesystem, you need to pass extra arguments to the sm-perform command. E.g., the following command dumps the serialized JSON buffer to the file named outcome.json and writes all supported flat pattern representations (BREP, DXF, SVG) near it. 

> sm-perform -json outcome.json -flat

You can now open the saved DXF drawing with your tool of choice (e.g., QCAD).

The exported flat pattern's drawing contains several layers. The layer named FLAT_PATTERN contains the cutting contours for all pierces to be done at the cutting stage of manufacturing. Another layer named FOLD_LINES comes with dashed-line representations of the bending lines.

Feature-recognize DXF

Commercial

You can read the DXF file of a flat pattern with the dxf-read command of Analysis Situs. This command turns all layers of the input drawing into their corresponding geometric primitives. It is useful mostly for consulting the geometry of a drawing because this command does not perform contour recognition.

To extract all cutting contours of a drawing, use another command named dxf-peform. This command performs 2D feature recognition at the level of the geometric primitives. This is where the commercial DXF SDK comes into play.

Extrude DXF into solid

Commercial

The JSON file generated by the dxf-peform command provides comprehensive information about cutting contours including the mutual nestings. This reported information can be turned into an input file for a contour extrusion utility named extrudeContourExe. A typical input for the contour extrusion utility looks as follows: 

{
  "inputDxf": "drawing.dxf",
  "originalUnits": "MM",
  "engravingColor": [255, 0, 0],
  "parts": [
    {
      "name": "Contour_1",
      "targetPartName": "test",
      "thickness": 10,
      "holes": [
        {
          "name": "Contour_2",
          "engraving": false
        }
      ]
    }
  ]
}

In this example, the drawing is composed of two contours: Contour_1 and Contour_2. The JSON input also tells the extruder that the Contour_2 is actually a hole inside the Contour_1. Other parameters include the material (extrusion) thickness (10 mm in this case) and the optional color for the top extruded face.

The geometry of the contours being extruded should be made available to the extrusion utility as BREP files named Contour_1.brep and Contour_2.brep in the case above. These files are exported by another utility named inspectDxfExe. This utility does effectively the same job as the dxf-peform command, although it is designed to be used hand in hand with the extrudeContourExe utility. For example, to inspect a DXF file with the possibility to extrude it later on, run inspectDxfExe utility as follows: 

  inspectDxfExe drawing.dxf inspectionOutput.json

This process prepares several files: JSON, glTF and a number of BREP files for the extracted cutting contours:

Using the information reported in the inspectionOutput.json, your application has to prepare a job file for the extruder, e.g., like the following one: 

{
  "inputDxf": "drawing.dxf",
  "originalUnits": "MM",
  "engravingColor": [255, 0, 0],
  "parts": [
    {
      "name": "Contour_1",
      "targetPartName": "test",
      "thickness": 10
    }
  ]
}

As long as there are no holes in our part, we do not need to populate the holes array in the job file. We now have the input file to run the extruder.

The extrusion utility is launched with a single argument being the input job file: 

  extrudeContoursExe extrusionInput.json
