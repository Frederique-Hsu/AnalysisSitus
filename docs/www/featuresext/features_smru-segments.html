SMRU contour segments

For precise cutter movement planning, SMRU can report elementary segments along the cutting contours, such as the flat pattern's outer perimeter and cutout features. Segments are reported at two levels:

  • The body level.
  • The cutout level.

In both cases, the format of reporting is the same, e.g.: 

"segments": [
  {
    "id": 2,
    "type": "line",
    "cuttingLength": 137.93114224133723,
    "middlePoint": [127.5, 70, 0],
    "nextSegment": 3,
    "angleToNextSegment": 133.53119928564325,
    "connectionPointToNextSegment": [80, 20, 0]
  },
  ...
]

To enable segments reporting in the sm-perform command, pass the optional -segments key. The same logic can be used from within C++ and asiSheetMetalExe executable. The following script illustrates a typical way of running the sheet metal recognition workflow with segments extraction turned on: 

> clear; sm-perform -filename azv_clamp.stp -segments

The angles between segments are measured based on the vertex vexity analysis.

The segments are reported in the order of traversal.
