Detect sharp corners

Sharp internal corners are difficult to process and require specialized machining operations which can be expensive. Milling cannot generate sharp inside corners, necessitating the use of different machining technologies such as EDM. Therefore, radiused corners are always preferable at the inner concave edges that are supposed to be side-milled.

CNC recognition workflow performs sharp corner detection by default. The detected issues are reported in the warnings JSON section with the code cncCode_PartBody_Warn_ImpossibleCorner as many times as many connected components (features) are detected. The corresponding vertex IDs are reported alongside with the face IDs. The problematic vertices can be located visually with the help of <Ctrl>+<V> key combination in the UI of Analysis Situs.
