Part thickness analysis

Overview

Two methods for thickness calculation are widely adopted in CAD/CAM/CAE applications: ray-based method and sphere-based method. The ray-based method measures the thickness value at each point by casting a ray orthogonally to that point until the intersection with the opposite surface element. The sphere-based method attempts to inscribe spheres into the solid body instead. While the ray-based method is easier to conduct, the thickness distribution obtained with that method is ambiguous. The point $\textbf{P}$ in the figure below can potentially get two different thickness values: $d_1$ or $d_2$, depending on how the measurement is done.

CNC recognition SDK implements ray-based thickness analysis. We adopt the convention that the thickness value at any point $\textbf{P}$ is measured by shooting a ray from this point ($d_2$). To perform thickness analysis together with CNC recognition, pass additional -tx argument followed by the minimal allowed value of thickness. E.g., the following example sets 2 [mm] as the minimal allowed thickness: 

> clear; load-part ex-milling_04.stp
> cnc-check -tx 2

The algorithm generates a quasi-uniform surface mesh for the part with reasonably small element sizes. The fineness of the mesh is chosen automatically based on the part's bounding box.

The constructed mesh is subjected to ray-based thickness analysis. All spots with the detected thicknesses less than the minimum allowed value are reported.

Some analytical properties of the detected "thin" spots are reported in the "dfm" / "thicknessAnalysis" JSON object.

Standalone check

It is possible to run thickness check independently from CNC recognition. For that, use the dfm-check-thickness command. This command also dumps the thin regions that are considered "false-positives" and therefore filtered out from the reported results. 

> clear; load-part ex-milling_04.stp
> dfm-check-thickness -t 2

The candidate "thin" regions are all reported as supplementary meshes under the "Tessellation" group in the project view.

Tips & tricks

Visualization

To inspect thickness analysis results in a more convenient way, use the following hints:

  • Keep only the "mesh" representation visible and toggle all other objects off.
  • Switch to wireframe by pressing <W> keyboard button.
  • Go to "Analysis Situs" root node and turn on the "Render HLR for meshes" mode.
  • Visualize thickness spots stored in the "thicknessSpot" object.

Punctual test

Analysis Situs allows for punctual thickness checks via the context menu. This is how you can verify the obtained thickness distribution in the detected "thin" spots.
