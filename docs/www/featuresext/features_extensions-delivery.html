Delivery of Extensions

Deliverables

Analysis Situs Extensions is a cross-platform SDK that can be delivered to the users in the following ways:

  • C++ libraries and header files for software developers.
  • Shallow C# wrappers for running SDK functions from C# applications.
  • Executables for running SDK functions as separate processes.
  • Docker images with Linux Ubuntu as a base image.
  • Source code.

The form of delivery depends on the use case and is agreed with SDK users in order to better meet their demands. Our clients create desktop and cloud-based apps, as well as integrate SDK features into existing CAD/CAM/CAE software.

Licensing

The following licensing models are available for the Extensions SDK:

  • Perpetual for unlimited seats (updates are not included).
  • Annual subscription (updates are included).
  • Exclusive right to use the SDK sources (updates are not included).

Normally, you select one of the three options listed above. Historically, the perpetual licensing model was the first we implemented. However, for small enterprises and start-ups, the subscription model looked to be more appealing because it is much cheaper and enables for updates at no additional cost. Upgrades to the perpetually licensed SDK are acquired on an annual basis.

The source-code delivery model inherits the principle of openly disseminating algorithms. The source-code package grants you unique rights to integrate the SDK into your application, with the possibility of customizing and adapting it to your specific needs. The intellectual property (IP) is not shared together with the SDK sources, therefore the algorithms remain the property of Quaoar Studio LLC.

How to get the SDK?

Contact us to learn more about the license rules and fees. Normally, we provide a trial version of the SDK as well as a collection of interactive applications for demonstration and suitability studies. The trial period is flexible and can be extended upon request.
