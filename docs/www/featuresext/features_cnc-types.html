Recognized CNC types

The following table provides a digest over the recognized production methods. The second column gives the string identifier of the process: CNC_LATHE, CNC_MILLING or CNC_LATHE_MILLING. All possible production types are defined in the asiAlgo_PartBodyType enum of Analysis Situs.

Turning CNC_LATHE

The default CNC recognition workflow starts with trying to recognize the input part as a turned one. At this stage, the algorithm looks for axial symmetries in a part. All turning and boring candidate faces are collected and labeled, while those that lack axial symmetry (with respect to a "most voted for" axis) are tagged as "unrecognized." If the contribution of the labeled faces outweighs that of the "unrecognized" ones, the part is decided to be lathed. If there are no "unrecognized" faces, the part is deemed to be turned.

Milling CNC_MILLING

Milling is the most generic type in terms of "mathematics of shape." A milled shape lacks the distinctive symmetries of lathed parts, because there is no specific axis (like the "turning axis" in the case of lathing).

Turning + Milling CNC_LATHE_MILLING

If a part is identified as lathed but certain faces remain in the "unrecognized" category of features, these faces are classified as milling features. The milling recognition algorithm begins to operate for the discovered "unrecognized" faces only.

At the end of the process, the results of milling and turning recognition are merged into a single data structure. Ambiguities are avoided, i.e., if a face was recognized as turned, it won't be reported as a milling feature.
