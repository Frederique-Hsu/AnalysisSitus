SMRU scene tree

When processing assemblies, the client application might need to incorporate the product hierarchy and its as-designed view. At the same time, SMRU and other Analysis Situs recognition tools operate at the level of a single B-rep solid (often a single CAD part). Nonetheless, SMRU is capable of acquiring scene tree data. Depending on the delivery form, this mode is activated in different ways as described below.

With the "scene tree" mode activated, the outcome JSON gets "sceneTree" node that holds the information about unique prototypes, roots and instances.

The format of the scene tree follows the specification of "Assembly JSON hierarchy".

CLI

To extract the scene tree in the CLI mode, use -model key followed by the model name. This option instructs SMRU to keep the assembly document in memory rather than releasing it upon completion of the recognition process. 

> sm-perform -filename /data/public/cad/chassis.stp -model M

C++ SDK

To dump the scene tree programmatically, make sure to pass false to the SetReleaseDocument() method of the InspectFile tool class: 

// Prepare inspector.
InspectFile inspector(cadFilename, progress, nullptr);
//
inspector.SetReleaseDocument(false); // Keep the document in memory.

Executable

If SMRU is used as an executable, then to render the scene tree in the outcome JSON, pass -asm key. E.g.: 

./asiSheetMetalExe.sh /data/public/cad/chassis.stp outcome.json -asm
