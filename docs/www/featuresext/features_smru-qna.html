SMRU FAQ

Question: After analysis, a seemingly valid sheet metal part remains unrecognized. What is the problem?
Answer:

It might help to check the face IDs reported in the smruCode_PartBody_Err_UnrecognizedFaces (3103) semantic code in the JSON outcome. This array contains all faces that could not be properly recognized by the SMRU algorithms.

Such issues often indicate design problems with the part being analyzed. Copy the face IDs from the JSON output and search them up in the part using the <Ctrl>+<F> key combination (with the active focus on the Part Viewer). To locate the found faces in the viewer easily, use the context menu's "Set as variable" action.

You will be able to isolate the problematic faces in the viewer by hiding the part. In the example above, the problematic thickness faces have unexpected machining features over their edges. For correct processing, these fillets or chamfers should be defeatured.


Question: Is there a way to adjust the hole sizes in the flat pattern?
Answer:

That is doable through the underlying OpenCascade API. We use such functionality to report correctly sized circles for machined holes with countersinks and counterbores. Read more about this feature on our blog: "On sheet metal unfolding. Part 7: drilled holes".


Question: Is there a way to save each body as its own STEP file?
Answer:

Yes, there is a dedicated flag "-step" that activates dumping each body to a STEP file. E.g.: 

 > sm-perform -filename test.stp -json outcome.json -step

Question: I find it strange that flat parts aligned on the Y, bent parts on the X and tubes on the Z. Do you not think it would make sense to align these different types of models along the same axis?
Answer:

The alignment procedure first checks if a part is aligned with one of the primary projection planes or axes. As a result, if a tube is initially aligned with X, Y or Z, it will remain in that position. The same holds true for flat and folded metals, therefore a part can be kept with its original orientation to minimize unnecessary relocation. This initial "as designed" diversity, combined with our desire to prevent unneeded transformations (which some people may find "strange" from their perspective), makes it difficult to establish a "one and for all" orientation convention.


Question: When using the SDK, a DXF of the unfolded STEP file is generated. Is there a feature to also output a DXF of the original state before unfolding?
Answer:

Nope, the folded state is not dumped to DXF or SVG. To preview solid models, we normally recommend dumping a PNG image with adjustable colors and hidden lines organically eliminated (due to shaded view).

Question: A visually correct part is labeled with the "abnormal bend" error code. Is there anything particularly wrong with the geometry?
Answer:

"Abnormal" bends typically occur when SMRU is unable to match pairs of cylindrical surfaces. It could be a situation of missing bends or uneven thickness at a bend feature caused by misaligned axes or mismatched radii. One criteria that can be easily checked on a part is that the difference between bend radii should be equal to the part's thickness, i.e., $r_o - r_i = t$, where $r_i$ is the inner bend radius, $r_o$ is the outer bend radius, and $t$ is the material thickness.

In the above example, the radii differ by 2 millimeters, but the sheet thickness is 3 millimeters. Therefore, a warning is reported.


Question: The JSON output of SMRU reports both drilledHoles and cutouts sections with the same face IDs. Why is that?
Answer:

Sheet metal manufacturing includes a combination of primary and secondary machining operations. The primary operations are cutting and bending (or rolling). Secondary processes include deburring, drilling, and edge machining. Because SMRU cannot (and should not) predict the cutting method (which may be laser, plasma, or waterjet technology), the algorithm is unable to determine which features should be drilled and which should be cut. For example, a circular hole can be made on a laser machine alongside contour cutting, however drilling may be required for thicker materials if waterjet cutting is utilized and the hole diameter is small.

As a result, a feature that allows for cutting OR drilling is reported twice. The client application decides which process should be used for a feature, and the corresponding properties can be taken from either the drilledHoles or the cutouts arrays.
