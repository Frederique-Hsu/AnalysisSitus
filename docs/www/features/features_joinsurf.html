JOINSURF: join surfaces

The JOINSURF operator works on a pair of naturally parameterized spline surfaces. If the argument surfaces are not parameterized naturally (i.e., their UV domains are not the aligned rectangles), consider applying the UNTRIM operator first.

To perform JOINSURF, the user calls the context menu and selects the "Join surfaces..." command.

Because the algorithm relies on GORDON, the number of "guide" and "profile" curves must be specified. The "guide" curves will be shared in the final surface, therefore there is just one parameter for the Num. guides.

To compensate for possible defects near the common boundary between the two surfaces, the Boundary offset parameter is used.

The resulting surface is a naturally parameterized spline.
