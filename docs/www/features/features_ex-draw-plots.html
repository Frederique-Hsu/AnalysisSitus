Draw plots

To generate a two-dimensional plot filled with one or more functions, use the draw-plot Tcl command. With this command, we can prepare graphs for further analysis and also for scientific publication (as they can be dumped to SVG format). Example of command usage: 

  draw-plot 1 0.083579 2 0.143794 3 2.306677 4 5.008208 6 3.694496 7 4.674164

We frequently collect execution time measurements during heavy algorithm runs and provide the results as a graphic for additional analysis. To capture execution time measurements, the following C++ code is quite useful: 

  TIMER_NEW
  TIMER_GO
  
  // Run your algorithm
  
  TIMER_FINISH
  TIMER_COUT_RESULT_NOTIFIER(progress, "Algorithm")
  
  // Compute the elapsed time in seconds.
  const double elapsedTime = __aux_debug_Seconds
                           + 60*__aux_debug_Minutes
                           + 60*60*__aux_debug_Hours;

The collected elapsedTime values can be dumped to a text file like the following code snippet shows: 

  static int __caseId = 0; __caseId++;
  {
    FILE* __pFile;
    errno_t err;
    err = fopen_s(&__pFile, "C:/users/serge/Desktop/timelog.txt", "a"); // !!! Change path
    if ( err == 0 )
    {
      fprintf(__pFile, "\n %d %f", __caseId, elapsedTime);
      fclose(__pFile);
    }
  }

The contents of the timelog.txt file can then be rendered as a plot.

To dump several charts at once, use the -numFunc <numFunc> parameter, followed by the number of functions being plotted. In this case, each argument value of x should be followed by precisely <numFunc> values of the functions to plot.

Example: 

  draw-plot 1 0.08 0.9 2 0.14 0.16 3 2.3 4.2 4 5.0 3.0 -numFunc 2

It should be noted that the -numFunc <numFunc> parameter should be specified at the very end of the list of command's arguments.
