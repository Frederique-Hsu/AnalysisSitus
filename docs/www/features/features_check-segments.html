Check segments

For CAM planning, it is often necessary to decompose a contour into elementary segments with their properties. E.g., for a contour composed of several edges, we might want to know the connection angles, their smoothness, the segment types and their lengths. This information can be extracted with the help of a dedicated check-segments-info command.

The extracted segments can be used to estimate machining time all over a contour. For example, in laser cutting, the tool may need to slow down at sharp corners while continuing uninterrupted travel across smooth connection points. The reported segments are visited in the order of their traversal. Each segment is numbered starting from 1.

To use the check-segments-info command, select a face of interest interactively and give this command a go in the Active Script panel. Alternatively, you may pass a face ID as an argument. 

 > check-segments-info -fid 8
