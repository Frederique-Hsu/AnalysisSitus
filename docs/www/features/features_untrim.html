UNTRIM: convert 4-sided surface

Surface trimming is a powerful modeling apparatus, although sometimes naturally bounded tensor-product surfaces are preferable. This can be the case during data exchange with older systems (e.g., ASTRA) or simulation model preparation for CAE (e.g., surface meshing). The UNTRIM operator converts a 4-sided trimmed surface into a geometrically equivalent surface in natural bounds, where the surface is parametrized over an axis-aligned UV rectangle. Such surfaces can be communicated across CAD software applications without topology.

The UNTRIM operator can be called both from the command line (used for testing) and from the user interface. To perform this operation, the user calls the context menu and selects the "Untrim surface..." command.

The U isos and V isos controls define how many isoparametric lines are to be generated in the corresponding curve network covering the initial surface. This network is generated on the equivalent Coons patch and then reprojected to the initial surface. The final surface is approximated with the GORDON operator.
