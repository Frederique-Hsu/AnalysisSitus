APPSURF2: approximate B-spline surface

To start with the surface fitting dialog, use the "Fit surface" command in the context menu of the Part Viewer.

This dialog allows to specify constraints of different types:

  • Edge constraints
  • Point constraints

The edges are normally taken from the active part. The edge constraints are implicitly turned into the corresponding point constraints by edge discretization. The following controls are exposed in the dialog:

  1. Method. This field allows to select one of the available approximation methods: PLATE (interpolation), APPSURF2 (approximation, the default one).
  2. Edge constraints. Enumerates the indices of the active part's edges to use as constraints. This list is synchronized with the interactive edge selection in the Part Viewer. The extra field Discr. step for the discretization step allows to refine the generated point constraints.
  3. Filename (xyz). This is an optional filename of the point database in XYZ format. All imported points are added to the table below.
  4. Table of points. Each point corresponds to a row in this table. The table allows for "smart" insertion and copying by blocks (e.g., from spreadsheets). The + button adds another point after the selected row or at the end of the table if no row is selected. The - button removes the selected row(s).
  5. Initial surface. It is the optional surface name of the initial surface to deform to get the resulting one.
  6. Fairing coeff. This is the fairing coefficient from 0 to +inf.
  7. U/V spans. How many knot spans the initial surface has in its parametric directions.
  8. U/V degree. B-spline degrees in U and V.

With each click of the Apply button a new surface is generated and is added under the "Surfaces" group in the project tree. This way, the user can visually check how each parameter of the dialog affects the approximation result.

If by the moment of the dialog's invocation there is an active part loaded in, Analysis Situs will automatically compute the value of Discr. step that can be refined later on by the user. By interactive picking of the model edges, the user populates the edge constraints list:

By constraining the resulting surface over the existing model's edges, it is possible to employ the "Fit surface" dialog for such scenarios as gap filling and face merge. If a closed contour is used as a constraint, the obtained surface is automatically trimmed to generate a topological face.

The constructed face can then be stitched into the original model.
