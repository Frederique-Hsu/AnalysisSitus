Export parts to glTF

An assembly can be exported to glTF format as a whole with the hierarchy preserved: 

asm-xde-load -model M -filename /data/cad/chassis.stp
asm-xde-generate-facets -model M
asm-xde-save-gltf -model M -filename chassis-asm.glb -scale 0.001

The resulting glTF file keeps the structure of meshes down to the colored faces.

It is possible to check the as-designed hierarchy of an assembly and dump it to a JSON file for reference.

Then, the parts of interest can be dumped to glTF files individually: 

asm-xde-load -model M -filename /data/cad/chassis.stp
asm-xde-browse -model M -title chassis
asm-xde-generate-facets -model M
asm-xde-dump-json -model M
sm-xde-save-gltf -model M -filename chassis-part-wheel.glb -scale 0.001 -part 0:1:1:3
